# Финальный аудит системы согласий

**Дата:** 2026-08-23  
**Ветка:** `cursor/legal-consent-audit-fd3f`  
**Формулировка результата:** реализовано согласно подготовленной юридической модели; перед публикацией требуется финальная проверка оператором/юристом.

---

## 1. Юридический чеклист

| Критерий | Статус |
|----------|--------|
| Отдельность согласий (ПД ≠ реклама ≠ распространение ≠ cookie ≠ политика) | ✓ |
| Конкретность целей и категорий ПД | ✓ (по фактическому функционалу) |
| Отдельность рекламы (необязательный checkbox) | ✓ |
| Отдельность распространения (unchecked, не молчание) | ✓ |
| Отзыв согласия (реклама, распространение в ЛК) | ✓ |
| Права субъекта (в Политике) | ✓ |
| Несовершеннолетние (без «только 18+») | ✓ |
| Третьи лица по категориям | ✓ |
| Локализация (Yandex Cloud РФ + риски Telegram/GA) | ✓ раскрыто |
| Версии документов | ✓ |
| Placeholders реквизитов | ✓ |

## 2. Frontend

## 3. Backend / Security

| Критерий | Статус |
|----------|--------|
| `accepted_at`, `document_version` — сервер | ✓ |
