# Wordstat и запросы (v4 этап 10)

Канон сайта: **https://tikhvin-palomnik.ru**. Техника SEO: [SEO_ADS.md](SEO_ADS.md). План: [V4_PLAN.md](V4_PLAN.md) этап 10.

Тексты туров, новости и юридичку **не выдумываем**. Частоты Wordstat в этот файл не подставлять «на глаз» — только выгрузка из кабинета владельца.

[Яндекс.Wordstat](https://wordstat.yandex.ru/) — кабинет владельца (тот же аккаунт, что Вебмастер / Директ, если есть). Регион для службы: **Санкт-Петербург и ЛО**, плюс сверка «Россия» без подмены локальной выдачи.

---

## Зачем

Подобрать формулировки, которые люди уже ищут (паломничество, туры, поездки, святыни), и **посадить их на существующие страницы**: главная, `/search`, `/tours/{slug}`, `/news`, карточки новостей. Не плодить отдельные «дорвеи» под каждый синоним.

Код: title / description / H1 / JSON-LD / slug берут формулировки из **CMS и карточек**, куда владелец (или агент по его тексту) вписал согласованные фразы. Пустые мета не заполнять нейросетью.

---

## Как снимать Wordstat (владелец или агент в кабинете)

1. Войти в Wordstat.
2. Регион: Санкт-Петербург, Ленинградская область.
3. По каждому кластеру ниже — точное и широкое соответствие; выписать частоту «в месяц» и похожие запросы.
4. Отметить запросы, под которые **уже есть** тур или новость. Нет страницы — не создавать фейковый маршрут; можно завести новость/описание **только с текстом владельца**.
5. Вставить цифры в таблицу (колонка «Wordstat») и дату снятия.

Пока цифр нет — кластеры это **гипотезы** из [SEO_ADS.md](SEO_ADS.md) и тематики службы, не измерение. На **2026-08-27 колонка Wordstat по-прежнему пустая** — снять частоты может только кабинет владельца.

## Кластеры → страницы

| Кластер (проверить в Wordstat) | Куда на сайте | Что править (не выдумывая текст) |
|--------------------------------|---------------|----------------------------------|
| паломничество, паломнические туры, паломнические поездки | `/`, `/search` | CMS title/description главной; H1 каталога «Расписание», если владелец подтвердит формулировку |
| паломнические туры из Санкт-Петербурга / из Питера / из СПб | `/`, `/search` | то же + контакт/отправка, если уже в настройках |
| Тихвин, паломничество в Тихвин, Тихвинский монастырь, Тихвинская икона | тур «Тихвинский путь» / Успение, новость про икону | title/description **карточки тура и новости** из уже опубликованного |
| святыни, святыни Тихвинской епархии | `/news/svyatyni-tikhvinskoy-eparhii` | уже есть статья; мета с названия со страницы |
| паломническая служба, паломническая служба Тихвин, епархия | `/` | имя сайта из настроек, не второе юрлицо |
| поездка в монастырь, паломническая поездка | `/search`, конкретный тур | только если тур опубликован |
| Оптина / Дивеево / Валаам и др. | **только** если появится активный тур с этим направлением | не создавать посадочную «под запрос» без тура |

`/search?q=...` в индекс не кладём (каноникал `/search`). Кабинеты — `noindex`.

Директ: те же проверенные запросы, URL только palomnik, цены в объявлении только с сайта. См. [SEO_ADS.md](SEO_ADS.md) §3.

## Внедрение в код (этап 10)

1. Закрыть дыры мета/canonical/OG/JSON-LD (уже в этапе 10).
2. Карта кластеров → URL в коде: [`frontend/src/lib/seo-wordstat.ts`](../frontend/src/lib/seo-wordstat.ts) (без выдуманных частот).
3. По таблице Wordstat: для каждой **существующей** страницы — title и description содержат 1–2 рабочих фразы, без переспама.
3. H1 = человеческий заголовок страницы (имя тура, «Новости», имя службы), не простыня ключей.
4. Внутренние ссылки: с главной и новостей на туры по смыслу, без линкфармы.
5. После выкладки: владелец смотрит Вебмастер → «Запросы»; агент не обещает «топ за неделю».

## Не делать

- Генерация описаний туров «под Wordstat»
- Скрытый текст, каталог ключей на одну страницу
- Покупные ссылки
- Новые URL-фильтры в sitemap
