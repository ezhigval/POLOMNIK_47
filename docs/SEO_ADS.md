# SEO и реклама (паломник)

Канон: **https://tikhvin-palomnik.ru**.  
API: `https://api.tikhvin-palomnik.ru`.

Поисковик не поднимает сайт «потому что код красивый». Первые строки — это совпадение запроса человека с **понятной страницей**, которой **доверяют** (ссылки, отзывы, карта, епархия) и которую **могут прочитать** роботы. Код даёт техническую базу. Места в выдаче даёт контент + кабинеты владельца.

Тексты туров, новости, юридичку и обещания в объявлениях **не выдумываем**.

---

## Что нужно, чтобы быть в первых строках

Три слоя. Без любого из них «топ» не случится.

### 1. Кабинеты поисковиков — только владелец

Без этого Яндекс и Google почти не знают, что сайт живой.

1. [Яндекс.Вебмастер](https://webmaster.yandex.ru/) — добавить `tikhvin-palomnik.ru`. Коды подтверждения уже в сайте:
   - мета-тег `yandex-verification`
   - файл `https://tikhvin-palomnik.ru/yandex_e79d1ee72d61fee0.html`
2. [Google Search Console](https://search.google.com/search-console) — мета-тег `google-site-verification` уже в `<head>`.
3. После деплоя этой ветки нажать «Проверить» в обоих кабинетах.
4. Отправить sitemap: `https://tikhvin-palomnik.ru/sitemap.xml`.
5. Проверить `https://tikhvin-palomnik.ru/robots.txt` (Host + Sitemap уже в коде).
6. В Вебмастере смотреть: индексирование, запросы, ошибки 4xx/5xx, «главное зеркало» `https://tikhvin-palomnik.ru` (без www).

Сменить коды можно через `NEXT_PUBLIC_YANDEX_VERIFICATION` / `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` (пересборка фронта). Текущие значения зашиты как запасные, секретами не являются.

### 2. Контент — главный рычаг (владелец + админка)

Робот ранжирует **страницу под конкретный запрос**. Для паломслужбы это обычно:

- «паломнические туры из Санкт-Петербурга»
- «паломничество в Тихвин / Оптину / Дивеево / Валаам»
- название службы и «Тихвинская епархия»

Что заполнять **вами**, без выдуманных текстов агента:

| Что | Зачем |
|-----|--------|
| Уникальное описание **каждого** тура (программа по дням, что включено именно в этот выезд) | Карточка тура — посадочная страница запроса |
| Реальные фото маршрута, не сток | Сниппет и доверие |
| Опубликованные отзывы с ответом службы | Яндекс смотрит живые отзывы |
| Новости/статьи про святыни и расписание | Внутренние ссылки и запросы «как доехать / что взять» |
| Title и description главной в CMS («Контент») | Сниппет в выдаче |
| Понятный slug тура (`tikhvin-path`, не UUID) | URL вида `/tours/tikhvin-path` |

Страницы-фильтры каталога (`/search?q=...`) в индекс **не** кладём: каноникал всегда `/search`.

Позже, когда будут целевые запросы от вас: отдельные посадочные под направления. Тексты — только ваши.

### 3. Техника — уже в коде и в этом PR

- Человекочитаемые URL туров `/tours/{slug}`; старый `/tours/{uuid}` отдаёт 301 на slug
- `robots.txt`, sitemap (главная, каталог, туры, новости, юр. страницы, CMS)
- Canonical, Open Graph, FAQ / тур / новость / хлебные крошки в JSON-LD
- `lang="ru"`, HTTPS, Host в robots
- Кабинеты, чат, личный кабинет — `noindex`

Проверить после деплоя:

- `https://tikhvin-palomnik.ru/sitemap.xml` — туры по slug, не UUID
- карточка тура: title с направлением, canonical на slug
- [validator.schema.org](https://validator.schema.org/) на главную и тур

### 4. Упоминания и доверие — не код

Яндекс для локальных услуг смотрит, кто ссылается и совпадает ли «название — телефон — сайт».

- Ссылка с сайта епархии [tikhvin-eparhia.ru](https://www.tikhvin-eparhia.ru/)
- Карточка организации в [Яндекс Бизнес / Картах](https://business.yandex.ru/) и 2ГИС: те же имя, телефон, сайт
- Каталоги паломслужб / епархиальные списки — только реальные размещения
- Регулярные новости и ответы на отзывы

Покупные «биржи ссылок» не используем.

### 5. Реклама — быстрее трафик, это не SEO

Директ и SEO дополняют друг друга. Объявления не заменяют индекс. См. раздел 3 ниже.

Сроки: после индексации первые запросы — недели; устойчивые позиции по конкурентным фразам — месяцы и зависят от контента и ссылок, не от ещё одного мета-тега.

## 1. Счётчики на сайте

В `.env.production` (и пересборка фронта):

| Переменная | Зачем |
|------------|--------|
| `NEXT_PUBLIC_YM_ID` | ID счётчика Яндекс.Метрики |
| `NEXT_PUBLIC_GA_ID` | ID Google Analytics (G-…) |
| `NEXT_PUBLIC_YM_WEBVISOR` | `1` — включить вебвизор (по умолчанию выкл.) |
| `NEXT_PUBLIC_YM_CLICKMAP` | `0` — выключить карту кликов (по умолчанию вкл. при Метрике) |
| `NEXT_PUBLIC_SITE_URL` | `https://tikhvin-palomnik.ru` |
| `NEXT_PUBLIC_YANDEX_VERIFICATION` | Код из Яндекс.Вебмастера (мета-тег) |
| `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` | Код из Google Search Console |

Пустые ID — скрипты и мета-теги подтверждения не подключаются, сайт не ломается.

Цели (reachGoal / GA events): `tour_view`, `begin_checkout`, `booking_submit`, `support_contact`.

## 3. Яндекс.Директ / VK Ads

В объявлениях:

- **URL сайта:** `https://tikhvin-palomnik.ru`
- **Целевые страницы:** `/` · `/search` · `/tours/{slug}` · `/support`
- **Счётчик Метрики:** тот же `NEXT_PUBLIC_YM_ID`
- UTM-пример:  
  `https://tikhvin-palomnik.ru/search?utm_source=yandex&utm_medium=cpc&utm_campaign=pilgrimage`

Не указывайте в рекламе выдуманные цены и отзывы — только то, что на сайте.
